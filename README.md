# ReadBlank Qt

A Qt Widgets desktop application for reading web content.

## Requirements

- Qt 6.5 or later
- C++17
- CMake 3.21 or later
- Ninja
- libxml2

## Build

```bash
cmake -S . -B build -G Ninja
cmake --build build
```

## Run

```bash
./build/readblank-qt
```
